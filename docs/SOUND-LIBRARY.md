# Sound library

Rule: **only ship sounds that are CC0, recorded or synthesized by us, or explicitly licensed for commercial redistribution inside a product.** Every sound has a manifest entry, and the credits page is generated from the manifest, not written by hand.

## Why this matters

A beatmaking product that bundles sounds it cannot redistribute is a legal liability and puts every user's released music at risk. "Free to download" is not "free to redistribute". We verify the licence text per library, record it, and keep a copy of the licence in the repo.

## Candidate sources (verify the licence text before adding anything)

| Source | What | Licence as understood | Action before shipping |
| --- | --- | --- | --- |
| Versilian Community Sample Library (VCSL) | Orchestral and world instruments | CC0 | Confirm on the project page; keep a copy of the notice. |
| Salamander Grand Piano | Multi-sampled piano | CC-BY-3.0 | Attribution required; confirm the terms allow commercial redistribution inside a product. |
| FreePats | Instruments, various | Per-library licences (some CC0, some CC-BY, some GPL) | Check each library; exclude anything copyleft that would affect the product. |
| Own synthesized drums, 808, keys, pads | Generated by the engine | Ours | Default kit. These ship first and need no third-party licence. |
| Own recordings | Percussion, vocals, textures | Ours | Record with signed releases for any performer. |
| Commissioned packs | Genre-specific kits | Work-for-hire or licence that allows redistribution | Contract per pack; keep the paperwork. |

Things we do not do: scrape sample sites, include "royalty-free" packs whose licence forbids standalone redistribution, or ship anything extracted from commercial records.

## Manifest

Every shipped sound has an entry in `apps/web/public/sounds/manifest.json` (planned):

```json
{
  "id": "kit-trap-01/kick-03",
  "name": "Kick 03",
  "file": "kit-trap-01/kick-03.flac",
  "kind": "one-shot",
  "tags": ["kick", "trap", "punchy"],
  "bpm": null,
  "key": null,
  "durationMs": 640,
  "license": "own",
  "licenseUrl": null,
  "author": "Forge",
  "attribution": null,
  "sha256": "..."
}
```

A CI check fails the build if a file in `public/sounds` has no manifest entry, a manifest entry has no `license`, or a `CC-BY` entry has no `attribution`.

## Delivery

- Small default kit is bundled for instant first sound; larger libraries stream on demand from object storage and are cached in OPFS.
- Files are stored losslessly (FLAC) and served as-is; the browser decodes once and the peaks for the waveform preview are computed at import and cached.
- The browser shows key and BPM for every sound; the values come from the analysis in `@forge/engine` (YIN pitch for one-shots, loop finder for loops) and are stored in the manifest so users do not wait for analysis.

## User-imported sounds

Users can import their own files. They stay on the user's device (or in their private cloud space) and never enter the shared library. The sample flip lab (see BEYOND-FL) records where a sample came from so the clearance helper can list it. That helper is informational and is not legal advice.
