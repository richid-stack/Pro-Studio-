# Security policy

Pro Studio is pre-release. If you find a security problem, please report it privately through GitHub: **Security tab > Report a vulnerability** (private vulnerability reporting). Do not open a public issue for it.

Include what you found, how to reproduce it, and the impact you expect. You will get an acknowledgement; there is no bug bounty yet.

Scope that matters most: accounts and sessions, project and asset access control (one user reading another's data), file uploads, and anything that handles user audio.
